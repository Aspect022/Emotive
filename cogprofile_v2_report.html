2. Architecture Overview

CogProfile-Net v2 is a multi-modal dual-branch model. Each EEG window is processed simultaneously through two complementary pathways before being fused for classification.

Branch A — Scalogram CNN

What: Continuous Wavelet Transform (CWT) across 1–45 Hz, then processed by an EEGNet-style CNN with depth-wise separable convolutions.

Why: CWT provides high time-frequency resolution simultaneously. Depth-wise convolutions extract channel-specific patterns efficiently without overfitting to individual subjects.

Branch B — Riemannian SPD

What: EEG covariance matrices are computed per window, then projected through BiMap, ReEig, and LogEig layers onto the tangent space of the SPD manifold.

Why: Covariance matrices lie on a Riemannian manifold — flattening them distorts geometric relationships. Riemannian layers respect the underlying geometry, capturing functional brain connectivity faithfully.

Attention Gate Fusion

What: A learned sigmoid gate dynamically weights z_A and z_B before producing the joint embedding z.

Why: Different tasks demand different modalities. Mental arithmetic uses more frontal connectivity (Branch B), while visual tasks rely on alpha-band power (Branch A). The gate adapts automatically.

Evidential Deep Learning (EDL)

What: The classification head outputs parameters of a Dirichlet distribution rather than a Softmax vector, yielding explicit uncertainty estimates.

Why: Standard Softmax is overconfident on noisy EEG. EDL distinguishes data uncertainty (noise) from model uncertainty (ignorance), so the system can flag when it doesn't know rather than producing a false confident prediction.

Deep Embedded Clustering (DEC)

What: An unsupervised centroid-based clustering loss encourages the latent space z to form tight, well-separated clusters.

Why: Well-separated clusters in latent space enable more reliable downstream analysis (digital twins, Markov chains). DEC jointly trains with the supervised loss so clusters align with true cognitive states.

4. Why 82%? — Bottleneck Analysis

The primary bottleneck is not model capacity or architecture but cross-subject EEG variability — a well-known problem in BCI research sometimes called the "neural fingerprint" problem.

Inter-Subject Covariate Shift

Each person's EEG amplitudes, impedances, and spatial patterns differ substantially even for identical cognitive tasks. A model trained on 24 subjects and tested on 1 unseen subject sees a fundamentally different input distribution — the EEG effectively looks like a different modality. This single factor accounts for the majority of the gap between 82% and the theoretical ceiling of ~90%.

Limited Labelled Data per Subject

With 25 subjects and ~2,900 trials, each subject contributes only ~116 trials. The current supervised training loop sees these 2,900 trials windowed into ~37,000 1-second segments (STEP=32), but they share the same 25 subjects. Better representation learning from the unlabelled portions of each subject's data would help generalise across the subject boundary.

Academic Context: For 14-channel consumer-grade EEG (Emotiv EPOC), 5-class LOSO classification benchmarks across the literature report 78–86% accuracy with state-of-the-art methods. Our 81.99% (cross-trial) is competitive at baseline. The realistic accuracy ceiling for this dataset is approximately 85–88%, achievable with the domain adaptation techniques described in Section 5.

5. Planned Improvements — Future Scope

The following improvements are planned for the next training run (CogProfile-Net v3). They are grouped into two phases based on implementation complexity and expected impact.

Target: CogProfile-Net v3 is expected to achieve 86–89% accuracy on the same dataset by addressing cross-subject variability through self-supervised pre-training, domain adaptation, and advanced augmentation.

Phase B — Self-Supervised Pre-Training (SimCLR)

SimCLR Contrastive Pre-Training

What: Before supervised training, the encoder is pre-trained using SimCLR — a self-supervised contrastive learning framework. Two augmented views of each EEG window are created, and the encoder is trained to produce similar representations for views of the same window while pushing apart representations of different windows.

Why: Self-supervised pre-training uses all data (including unlabelled portions) to learn general EEG representations before fine-tuning on labels. The encoder develops robust features that are less sensitive to subject-specific noise, leading to better generalisation when tested on new subjects.

Expected gain: +2–4% over supervised-only baseline. The projection head used during Phase 0 is discarded before supervised fine-tuning — only the encoder weights are retained.

Phase C — Domain Adaptation (Cross-Subject)

Euclidean Alignment (EA) — Per-Subject Covariance Whitening

What: Before any feature extraction, each subject's EEG windows are whitened by their mean spatial covariance matrix. For subject i, we compute R_i = E[x·xᵀ] across all windows, then apply the transformation x_aligned = R_i^-0.5 · x.

Why: This removes between-subject amplitude and impedance differences at the source — before the signal enters any neural network layer. Because EA is computed from raw signals (no labels needed), it applies equally to unseen test subjects during evaluation.

Expected gain: +2.5–3.5% accuracy. One of the highest-leverage, lowest-complexity improvements available for cross-subject EEG.

Adaptive Batch Normalization (AdaBN)

What: At inference time (per test subject), the Batch Normalization running statistics (μ and σ²) are reset and recomputed from that specific subject's unlabelled windows via a single forward pass. Only the running statistics change — learned scale (γ) and shift (β) remain fixed.

Why: Standard BN statistics are computed during training across all training subjects. When the model encounters a test subject with a different EEG distribution, these statistics are mismatched, causing a drop in feature quality. AdaBN recalibrates the deep feature distribution to each individual test subject at no cost.

Expected gain: +1.5–2.5% accuracy.

Phase D — Augmentation & Inference Improvements

SpecAugment on CWT Scalograms

What: During training, random frequency bands (8 consecutive bins) and random time segments (15 consecutive steps) in the scalogram are zeroed out with probability 0.5.

Why: Originally developed for speech recognition, SpecAugment forces the model to rely on multiple frequency bands and time points rather than memorising specific spectral signatures. This significantly improves generalisation to new subjects whose frequency profiles differ.

Expected gain: +1–2% accuracy.

Bilateral Electrode Permutation

What: During training, homologous bilateral electrode pairs (e.g., AF3↔AF4, F7↔F8, T7↔T8) are randomly swapped with probability 0.25 per pair.

Why: People differ in hemispheric dominance and lateralisation of cognitive processes. Random bilateral swaps teach the model that both hemispheres can carry similar task-relevant information, reducing sensitivity to individual lateralisation patterns.

Expected gain: +0.5% accuracy.

Manifold Mixup in Embedding Space

What: During training, with probability 0.5 per batch, two random samples' joint embeddings (z) are interpolated: z_mix = λ·z_i + (1−λ)·z_j, with labels similarly mixed. Classification loss is computed on z_mix.

Why: Standard Mixup operates on input pixels; Manifold Mixup operates in the learned latent space — a richer geometric interpolation that encourages smoother, more transferable decision boundaries. Working in embedding space preserves the Riemannian structure of the covariance branch.

Expected gain: +1–2% accuracy.

Test-Time Augmentation (TTA)

What: At inference, each test window is evaluated five times with different temporal shifts (−16, −8, 0, +8, +16 samples). The five Dirichlet evidence vectors (α) are averaged before taking the final prediction.

Why: Single-window predictions can be sensitive to exact temporal alignment. Averaging across small shifts produces a more robust, stable prediction — effectively an ensemble of five slightly different views of the same signal.

Expected gain: +1–1.5% accuracy.

EDL KL-Divergence Loss Fix (Phase 1)

What: The Phase 1 supervised training currently uses a plain NLL loss on the EDL log-probabilities. This will be replaced with the proper KL-regularised evidential loss: L = MSE(α/S, y_onehot) + λ(t)·KL[Dir(ã) ‖ Dir(1)], where λ(t) is annealed from 0 to 1 over 10 epochs.

Why: The proper KL penalty regularises the Dirichlet parameters toward the non-informative prior (uniform) when predictions are wrong, preventing overconfident evidence accumulation. The current NLL approximation does not enforce this and allows the model to become overconfident on noisy EEG.

Expected gain: +1–2% accuracy.

DEC λ Schedule + Confidence Gating

What: The DEC clustering weight λ is scheduled to ramp from 0 (epochs 1–10) to 0.02 (epochs 11–30), then held fixed. Additionally, the DEC loss only applies to windows where the maximum cluster assignment probability exceeds 0.7 (confidence gating).

Why: Applying full clustering pressure from epoch 1 with a fixed λ=0.01 can cause centroids to drift before the encoder has stabilised. The warmup schedule lets the encoder reach a good representation first. Confidence gating prevents noisy windows from corrupting centroid positions during joint training.

Expected gain: +0.5–1.5% accuracy (indirect — better cluster structure → better DEC-EDL co-training).

6. Broader Research Vision

Beyond accuracy improvements, this work is positioned within a broader two-paper research narrative:

Paper 1 — Unsupervised Digital Twin (Conference)

The unsupervised pipeline (CWT scalograms → Ruzicka similarity → K-Means → Hungarian matching → Markov chain) demonstrates that cognitive states can be reliably clustered and modelled as a digital twin without any labels. This is the novelty contribution: applying digital twin methodology to real-time cognitive state estimation from EEG.

Paper 2 — CogProfile-Net v2/v3 (Journal)

The deep learning extension (supervised + SimCLR + domain adaptation) pushes accuracy into the 85–89% range, enabling the cognitive state digital twin to function with high reliability in real-world conditions. Future extensions include career aptitude mapping (linking cognitive profiles to O*NET competency frameworks) and CHC-based psychometric integration.
